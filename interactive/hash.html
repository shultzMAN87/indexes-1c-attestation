Hash — корзины по хеш-коду

Индекс USING hash (url). Учебная модель: на странице корзины помещается 3 записи, корзина делится, когда записей становится больше 3 × число корзин. Хеш-функция — учебная (FNV-1a, 32 бита), принцип тот же, что у hashtext. Идите по шагам кнопкой «Дальше» или стрелками ← →. К разделу 3.1 методички.

Операция:
url = INSERT url = подсказки в списке: вставьте 2–3 строки подряд url LIKE %

Индекс: метастраница и корзины (основная страница + цепочка страниц переполнения)

Таблица (куча)

текущая страница / корзина хеш-код совпал сравнивается новое / переехало строка в результате отброшена перепроверкой страница переполнения

Что упрощено: настоящая страница вмещает сотни пар «код → ctid»; кроме корзин и страниц переполнения в индексе есть страницы битовой карты (учёт свободных страниц переполнения); новые корзины выделяются группами («точками расщепления»), а не по одной странице. Хеш-функция в PostgreSQL другая (hashtext, hashint8 …), но тоже даёт 32-битный код.
