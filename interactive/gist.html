GiST — R-дерево: ключ узла охватывает всё поддерево

Индекс USING gist (pos) по точкам на карте 100 × 100 км. Ключ записи во внутренней странице — ограничивающий прямоугольник всех точек поддерева; прямоугольники соседних страниц могут перекрываться. Учебная модель: в листе до 5 точек, во внутренней странице до 5 записей. Идите по шагам кнопкой «Дальше» или стрелками ← →. К разделу 3.1 методички.

Операция:
Протяните мышью прямоугольник на карте или: Щёлкните по карте, чтобы поставить точку Q. LIMIT Щёлкните по карте, где появится новая точка (попробуйте несколько вставок в одну область). Удалить все точки с x >

Карта: точки и прямоугольники-ключи

Страницы индекса

текущая страница ветвь подходит — спускаемся ветвь отсечена точка в результате новое / изменилось запрос

Что упрощено: на настоящей странице сотни записей; picksplit в PostgreSQL для точек сложнее (учитывает перекрытие и форму групп), здесь — разрез по оси с большим разбросом. Корень GiST всегда лежит в блоке 0: при его расщеплении содержимое переезжает в две новые страницы, а в блоке 0 остаётся новый корень. Для точек возможен Index Only Scan — точка хранится в листе целиком.
