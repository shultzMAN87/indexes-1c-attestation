B-tree — сбалансированное дерево (B+-дерево)

Индекс goods_code_idx по колонке code. Учебная модель: в листе помещается 4 ключа, во внутренней странице — 4 ссылки. Выберите операцию, задайте значения и идите по шагам кнопкой «Дальше» (или стрелками ← →). К разделам 1.2 и 3.1 методички.

Операция:
code = code BETWEEN AND LIMIT INSERT code = (попробуйте 50, затем 58, 99, 23)

Индекс: метастраница → корень → внутренние страницы → листья (связаны в двусвязный список)

Таблица (куча): страницы с версиями строк и карта видимости (VM)

текущая страница индекса уже прочитана выбранная запись сравнивается подходит под условие новое / изменилось страница кучи читается куча не нужна (all-visible)

Что упрощено: в настоящем индексе на странице сотни записей, а не 4; у не самых правых страниц есть ещё «high key» — верхняя граница ключей страницы; ключи внутренних страниц могут быть усечены (suffix truncation). Метастраница кешируется и в счётчике чтений обычно не видна.
