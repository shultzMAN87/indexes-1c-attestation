BRIN — сводки по диапазонам блоков

Таблица событий events(ts date) на 32 страницах, по 4 строки на странице, индекс USING brin (ts). BRIN не ищет строки — он отбрасывает диапазоны страниц, где нужных значений быть не может. Задайте условие и идите по шагам кнопкой «Дальше» или стрелками ← →. К разделу 3.1 методички.

Таблица (куча): страницы, сгруппированные в диапазоны блоков

Индекс BRIN

сводка пересекается с условием диапазон без сводки страница читается строка подходит отброшена перепроверкой «выброс»

Масштаб: по умолчанию pages_per_range = 128 (1 МБ таблицы на одну сводку), и на таблицу в 325 МБ приходится около 330 сводок — десятки килобайт. Здесь диапазон — 2–8 страниц, чтобы всё было видно. Кроме minmax и minmax_multi есть bloom (равенство по значениям без порядка) и inclusion (для box, inet, диапазонов).
